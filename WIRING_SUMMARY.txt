WIRING FLOW
═════════════════════════════════════════════════════════════════════════════

USER REQUEST (via API)
  │
  └─→ FastAPI Endpoint
       │
       └─→ UnifiedWorkflowEngine.execute_workflow()
            │
            ├─ Get workflow definition (Piece 7: Data Storage)
            │
            ├─ For each task in workflow:
            │  │
            │  ├─ Create TaskExecution (Piece 4: Log)
            │  │
            │  ├─ Call Agent3Orchestrator.execute_task()
            │  │  │
            │  │  ├─ Generate action via LLM
            │  │  │  └─ Use Piece 2 credentials (groq_api_key, etc.)
            │  │  │
            │  │  ├─ Parse action via AgentS3Adapter
            │  │  │
            │  │  ├─ Execute action via DesktopExecutor
            │  │  │
            │  │  └─ Track cost via CostTracker
            │  │
            │  └─ Update TaskExecution with results (Piece 4: Log)
            │
            ├─ Create WorkflowExecution (Piece 4: Log)
            │
            ├─ Save to disk (Piece 7: Data Storage)
            │
            ├─ Publish events (Piece 6: Notifications)
            │
            └─ Return results

TRIGGERS
════════

1. Manual: POST /api/workflows/{id}/execute
   └─ Immediate execution

2. Webhook: POST /api/webhook/{webhook_id}
   └─ External event triggers workflow

3. Scheduled: APScheduler (Piece 3)
   └─ Cron expression triggers at scheduled time


PERSISTENCE ACROSS RESTARTS
════════════════════════════════════════════════════════════════════════════

On Startup:
  1. Load API keys from /tmp/agent_s3_api_keys.json
  2. Load workflow definitions from /tmp/agent_s3_workflows.json
  3. Load execution history from /tmp/agent_s3_task_executions.json
  4. Load webhook registry from /tmp/agent_s3_webhooks.json
  5. Recreate APScheduler jobs from workflow.schedule

On Shutdown:
  - All data already persisted to JSON files
  - No data loss
  - Full recovery on restart
